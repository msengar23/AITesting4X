# Taste — Communication & Workflow
- Communicates in short, terse instructions (e.g., "filled manually credential in .env file now continue"; "analyse these Test CAses is there any other testcases which has been added in this then add those also"; "use only template of .env file"; "skip all .env file content keep template"; "rewrite this md file for QA in technical term and add any type of info is missing and update this file in fine tune") and expects the agent to proceed autonomously without re-confirming or asking questions; if the agent drifts from the instruction, the user restates the same directive tersely rather than elaborating. Confidence: 0.9
- Provides highly structured task briefs for documentation work using labeled sections (Role, Instructions, Context, Example, Parameters, Output, Tone) that must be followed exactly. Confidence: 0.7
- Expects the agent to create/update README.md files for every folder in the repository (not just the root) as part of repo maintenance. Confidence: 0.8
- Expects the agent to commit and push completed work to the user's GitHub repository autonomously (per user-provided repo URL) as the final step of a task. Confidence: 0.9
- User's environment runs Windows (cmd.exe / PowerShell 5.1): bash-style heredocs (e.g., `git commit -F - <<'EOF'`) and PowerShell's `<<<` here-string redirect both fail and must not be used — for multi-line commit messages, write the message to a temp file and use `git commit -F <file>`, or use repeated `-m` flags. Confidence: 0.8
- When asking to rewrite/update an existing document, expects the changes to be applied in place to the same file path ("edit in the same file"), not delivered as a new or separate file. Confidence: 0.75
- Expects document deliverables to be produced in both Markdown (source) and PDF (rendered) formats — e.g., "make it in a md file as well as in pdf" / "make it in md file and pdf file both" / "add these tests also in both the TestCase.md and TestCase.pdf file" — generating the PDF from the MD (headless Chrome via marked + puppeteer-core) and verifying the PDF renders correctly before reporting done; amendments to a document must also land in both formats, not just the source. Confidence: 0.9
