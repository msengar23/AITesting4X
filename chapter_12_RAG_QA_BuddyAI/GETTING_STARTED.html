🤖 QA Buddy AI

Retrieval Augmented Generation System for QA Teams

Welcome to QA Buddy AI

QA Buddy AI is an intelligent question-answering system that retrieves answers from your entire QA knowledge base: test cases, Jira tickets, code repositories, meeting notes, requirements documents, and more.

Ask one question → Get a cited answer with sources highlighted.

🚀 Ready to start? Follow the steps below to set up and run the application on your local machine.

📋 System Requirements

Component Purpose Status on Your PC
Python 3.13+ Core application runtime ✓ Installed
Node.js 18+ Build the web UI ✓ Installed
Ollama Run embeddings locally ✓ Installed
Qdrant Vector database (local or Cloud) ⚠ Setup required
Groq API Key LLM for generating answers ⚠ Get free key
1

Pull Embedding Model

Download the Qwen3 embedding model to Ollama (this happens once).

ollama pull qwen3-embedding:0.6b

Verify with: ollama list

2

Set Up Vector Database

Option A (Recommended): Use Qdrant Cloud (free tier available)

OR

Option B: Run local Qdrant Windows binary in .qdrant-win/

curl.exe -L -o qdrant.zip https://github.com/qdrant/qdrant/releases/download/v1.19.1/qdrant-x86_64-pc-windows-msvc.zip
3

Configure Environment

Copy and edit the environment configuration file.

copy .env.example .env

Edit .env and add:
• GROQ_API_KEY (get from console.groq.com)
• QDRANT_URL & QDRANT_API_KEY (if using Cloud)

4

Build the UI

Compile the React frontend with Vite.

cd ui
npm install
npm run build
cd ..
5

Index Your Data

Build the searchable index from all data sources (test cases, Jira, docs, etc.)

python -m qabuddy ingest

First run takes 5-10 minutes. Then incremental.

6

Start the Application

Run the FastAPI backend which serves both API and UI.

python -m qabuddy serve

Open: http://localhost:8300

✨ Key Features

🧠 Hybrid Search

Combines semantic search (embeddings) with keyword matching (BM25) for best results.

📚 10 Data Sources

Indexes test cases, Jira tickets, documentation, code, meeting notes, and more.

🎯 Ranked Results

Uses cross-encoder reranking to find the most relevant answer first.

📌 Cited Answers

Every answer includes sources and exact chunks so you can verify it.

💬 Multiple Modes

Ask anything, analyze failures, design tests, triage bugs, or get coding help.

🔍 Retrieval Trace

See exactly how the system found your answer for debugging and transparency.
