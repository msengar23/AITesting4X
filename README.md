# AITesting4X

Research and reference documentation for Command Code slash commands.

## Commands Documented

- **`/goal`** — Sets a persistent agent objective that spans multiple turns, with self-directed execution and verifiable completion.
- **`/compact`** — Compacts conversation history to free up context window space, with configurable compaction modes.
- **`/mcp`** — Manages MCP (Model Context Protocol) servers to extend Command Code with external tools and data sources.
